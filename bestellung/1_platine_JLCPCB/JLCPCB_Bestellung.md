# Platine bei JLCPCB bestellen (unbestückt)

Die Datei **`GameboyPi_Gerber.zip`** in diesem Ordner ist die fertige Platine (78 × 134 mm, 2 Lagen). Sie passt genau ins 3D-Gehäuse.

## Schritt für Schritt

1. Auf **jlcpcb.com** ein Konto anlegen und oben auf **„Order now“** klicken.
2. **„Add gerber file“** wählen → `GameboyPi_Gerber.zip` hochladen (nicht entpacken!).
3. JLCPCB erkennt Größe (78 × 134 mm) und Lagen (2) automatisch. Folgende Einstellungen wählen:

| Einstellung | Wert | Hinweis |
|---|---|---|
| Base Material | FR-4 | Standard |
| Layers | 2 | wird erkannt |
| PCB Qty | 5 | Mindestmenge, kostet kaum mehr als 1 Stück |
| PCB Thickness | **1.6 mm** | wichtig: das Gehäuse ist auf 1,6 mm ausgelegt |
| PCB Color | **Purple** (passt zum GBX-Design) oder Black | Grün ist am billigsten und schnellsten |
| Surface Finish | **LeadFree HASL** | gut von Hand lötbar |
| Outer Copper Weight | 1 oz | Standard |
| Remove Order Number | „Specify a location“ oder „Yes“ | sonst druckt JLCPCB eine Nummer irgendwo auf die Platine |
| PCB Assembly | **aus** | du lötest selbst |

4. In den Warenkorb legen. JLCPCB prüft die Dateien kurz (Review, meist < 1 Stunde).
5. Versand nach Österreich wählen. Die österreichische MwSt. (20 %) wird bei JLCPCB direkt mitbezahlt, es kommt also kein Zoll oder Nachzahlung an der Tür.
